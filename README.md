## 作り方（v34〜）
このリポジトリは「作った結果」です。元は1つ（hack_src/src）で、同じ元からライフハック！も作ります。お店までの距離は阪急武庫之荘駅から測っています。通販・出前はカートに入れるところまでで、注文の確定と支払いは利用者が自分でします。

## 保存データの注意
買い物・家計・冷蔵庫・献立・合言葉は、開いているホストの localStorage にだけあります。バックアップに合言葉は入りません。

`github.io` はパスが違っても一つのオリジンです。このアプリをそこに置いているあいだは、同じホストの別ページから合言葉を読めます。キーの名前を変えることや、同じ場所に復号鍵を置く暗号化では防げません。本体は github.io ではない専用ホスト（例: Cloudflare Pages の `*.pages.dev`）で開きます。専用ホストは `data/public-origin.json` の `origin` に https で書きます。github.io 側は書き出しと、合言葉を消す案内だけです。

移すときは、古いアドレスで「全部を書き出す」、専用アドレスで「読み込んで戻す」、合言葉は専用アドレスの設定で入れ直す、そのあと古いアドレスの合言葉を消します。中継の合言葉そのものは、アプリからは変えません。
